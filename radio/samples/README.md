# BWATCH Radio samples

Trimmed, mono MP3 excerpts (one dynamic level, a note every four semitones) from the
**Versilian Community Sample Library** by Versilian Studios, released under **CC0 1.0**
(public domain): https://github.com/sgossner/VCSL

- `upright/` Upright Piano, Knight (Sustains, vl2). Used by the Lo-fi station.
- `fmpiano/` Yamaha TX81Z FM Piano (vl2). Used by the Late Night station.

File names are MIDI note numbers.
- `drums/` hi-hats, snare, claps, shaker and a suspended-cymbal crash, also from VCSL (CC0). Used by Beats.
- `voice/` the digits 0-9 for the Shortwave numbers station, synthesized with Flite's "slt" voice
  (CMU Flite, BSD-style licence), trimmed and normalized.
